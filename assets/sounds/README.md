# Weky Dashboard Audio Assets

This directory contains MP3 audio assets used by the **Weky Dashboard Soundboard Engine** (`SoundboardManager`).

## Available Audio Cues:
- `victory.mp3` - Fanfare played when a player wins a match or achieves a high score
- `defeat.mp3` - Audio played on defeat or game over
- `action.mp3` - Button click and card selection feedback
- `countdown.mp3` - Timer tick for fast-paced rounds
- `hit.mp3` - Impact strike sound for Fight RPG
- `heavy_hit.mp3` - Deep critical strike sound for Fight RPG
- `heal.mp3` - Magic chime for recovery and shields
- `eat.mp3` - Retro sound for Snake food and 2048 merges
- `tie.mp3` - Match tie / draw sound
- `gamestart.mp3` - Arcade coin drop / round start sound
- `win_streak.mp3` - Combo sound for 3+ win streaks

Web dashboards can reference these files locally via `/assets/sounds/[name].mp3` or via CDN.
